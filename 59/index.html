e-GIS 프롬프트 기록

e-GIS(e-gis.kr)를 만들면서 Claude Code에 입력한 프롬프트를 날짜, 시간, 요청 종류, 다룬 기능으로 나눠 봤어요. 숫자는 이 PC에 남은 기록에서 자동으로 센 값이고, 나눈 방법은 맨 아래에 적었어요.

일자별 프롬프트 수

칸 하나가 하루예요. 색이 진할수록 그날 입력한 프롬프트가 많아요. 칸에 마우스를 올리면 날짜와 개수가 보여요.

주별 흐름과 커밋

위는 한 주 동안의 프롬프트 수, 아래는 같은 주에 e-GIS 저장소에 남은 git 커밋 수예요. 두 그래프는 같은 주끼리 위아래로 맞췄어요.

월별 프롬프트 수

가장 많이 입력한 날

    요일과 시간

    언제 개발했는지 보여 줘요. 가로는 시각(0시부터 23시), 세로는 요일이에요.

    요청 종류

    프롬프트마다 가장 가까운 종류 하나를 골랐어요. 막대에 마우스를 올리면 예시 프롬프트가 보여요.

    달마다 각 종류가 몇 개였는지 보여 줘요. 색이 진할수록 많아요.

    다룬 기능

    프롬프트에 나온 낱말로 어떤 기능을 다뤘는지 표시했어요. 한 프롬프트가 여러 기능에 들어갈 수 있고, "응"처럼 기능 낱말이 없는 프롬프트는 세지 않았어요.

    프롬프트 길이

    붙여넣은 글을 뺀, 직접 입력한 글자 수예요.

    입력 방식

      프롬프트 찾아보기

      원문을 종류, 기능, 달, 낱말로 골라 볼 수 있어요. 키, 이메일, 비밀번호처럼 보이는 글자는 가렸어요.

      자료와 분류 방법
