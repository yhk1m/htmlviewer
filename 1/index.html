    조건이 많을수록 사람이 하기 귀찮은 일

    볼 점

    • 조건 네 개를 한 번에 걸러냄

    • 예약 버튼 앞에서 멈추고 보고

    실습 1: 로그인 없이 조회·비교

    둘 중 하나를 골라 그대로 입력해 보세요

    A · 기차 코레일에서 11월 7일 토요일 오전 9시 이후 서울→부산 KTX 시간표를 조회해서 소요 시간과 일반실 요금을 표로 보여줘. 예매는 하지 마.
    B · 전시 이번 주말 서울에서 열리는 전시 5개를 찾아 장소, 관람료, 운영 시간을 표로 정리해 다운로드 폴더에 저장해줘.

    이유로그인 없는 조회부터 시작하면 막히는 사람이 적고, 결과 파일은 태스크 상세 화면에서 바로 미리 볼 수 있습니다.

    실습 2: 교보문고에서 책 주문하기

    Aside사람
    ASIDE로그인 페이지 도착주소를 확인하고 저장된 계정을 찾음
    ASIDE비밀번호 자동 입력원문은 AI에게 보이지 않음
    사람MFA · CAPTCHA나오면 태스크가 멈춤. 처리하면 이어감
    ASIDE장바구니 · 주문서책을 찾아 담고 배송지와 수량까지 채움
    사람결제 승인카드사 앱 인증, 간편결제 비밀번호
    태스크 교보문고에 로그인해서 『○○○』 종이책을 찾아 장바구니에 1권 담고, 기본 배송지로 주문서까지 작성해줘. 쿠폰·적립금은 쓰지 말고, 결제 버튼 누르기 전에 멈춰서 최종 금액을 알려줘.

    실습 3: Canva·미리캔버스로 수업 자료

    두 서비스에 미리 로그인해 두세요

    A · 미리캔버스 미리캔버스의 무료 가정통신문 템플릿 중 깔끔한 것 하나를 골라 제목을 ‘11월 현장체험학습 안내’로 바꾸고, PNG로 다운로드 폴더에 저장해줘.
    B · Canva Canva에서 16:9 프레젠테이션 무료 템플릿으로 ‘기후 변화와 우리 생활’ 수업 슬라이드 5장을 만들어줘. 장마다 제목과 핵심 문장 한 줄만 넣고, 공유나 게시는 하지 마.

    단순한 일부터

    편집 화면은 클릭과 드래그가 많아 조회보다 느립니다. 템플릿 고르기, 문구 바꾸기부터 시켜 보세요.

    ‘무료만’ 조건 넣기

    유료 요소가 섞이면 워터마크가 남거나 결제 화면으로 넘어갑니다.

    학생 정보는 빼기

    학생 사진, 실명, 연락처는 넣지 말고 완성본에서 직접 채웁니다.

    아이디·비밀번호 저장하기

    Settings > Passwords

    로그인할 때 저장

    Use default password manager를 켜 두고 직접 로그인하면 저장 제안이 뜸

    한꺼번에 가져오기

    Data management > Import. Chrome, 1Password, Bitwarden 등 CSV. 이후 변경은 따라오지 않음

    외부 관리자 연결

    Connect external password manager. Aside 안에 그 관리자의 확장을 설치해야 동작

    Always allowWhile unlockedNever

    AI 에이전트 접근 정책의 기본값은 Always allow입니다. 개인 메일·금융 계정이 있다면 지금 같이 바꿔 둡시다.

    권한은 세 단계

    태스크 입력창 아래 권한 메뉴

    Read only

    브라우저와 파일을 읽기만 하고 아무것도 바꾸지 않음

    Guard 기본값

    승인된 폴더 안에서만 일하고, 다른 폴더는 물어봄

    Full access

    컴퓨터 어디든 읽고 씀. 오늘 실습에서는 쓰지 않음

    켜기같은 메뉴의 Final confirm 스위치를 켜 둡니다.
    참고Full access여도 저장된 비밀번호 값은 에이전트에게 보이지 않습니다.
